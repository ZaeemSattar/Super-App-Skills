###  Application life cycle

`Mini App` supports application lifecycle functions such as onLaunch, onShow, onHide, etc. For details, please refer to [Application Lifecycle](https://miniapp.neuxnet.com/collocation/frame/lifecycle#app)

###  Page life cycle

`Mini App` supports life cycle functions such as onLoad, onShow, onReady, etc. For details, please refer to [page life cycle](https://miniapp.neuxnet.com/collocation/frame/lifecycle#page)
