####  What is a compiler

-   Compiler: Compile the `Mini App` unified code to generate the unique code supported by each platform;
-   Runtime: Dynamically process data binding and event proxy to ensure the consistency of Vue and platform host data;

The `Mini App` project has different compiler implementations depending on the version of `Vue` it depends on:

-   vue3: The `Mini App` compiler is implemented based on Vite, and the compilation speed is faster.
