####  Preparation conditions

-   Access to Google servers Note: Google servers cannot be accessed within China
-   Register a Google account

####  Android activation steps

-   Open the Google login guide page URL: https://developers.google.com/identity/sign-in/android/sign-in?hl=en-us
    
-   Select project configuration ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/636a9bd3-77d7-4539-b46c-0c798eb49350.png) ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/f206ec8a-c82d-41f4-9e6d-d838e21a4857.png)
    
-   After selecting a project, create a new application under the project ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/09c5a8aa-c698-4133-9a11-d73d59e37da5.png) ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/d14feca3-94b5-467e-b197-d98b866072bc.png) Click Create to complete the activation steps.
    

####  iOS activation steps

-   Open [Google Sign in iOS Boot Page](http://developers.google.com/identity/sign-in/ios/start-integrating?hl=zh-cn)
    
-   Click to create OAuth client ID, fill in the project name ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/1978e9aa-5e11-4586-9caf-1c1b7c3e71bd.png)
    
-   Select the iOS platform, fill in the BundleID, and click CREATE to get the Client ID ![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-f184e7c3-1912-41b2-b81f-435d1b37c7b4/26045e0b-b6f0-4c22-aa61-0d63120e1a4b.png)
