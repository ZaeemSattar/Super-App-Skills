## Install the skills

Open the **974 Super App Skills** icon in the activity bar, then click
**Install All Skills** in the view's title bar.

Each skill shows a badge:

- ○ not installed
- ✓ installed

Hover a skill to read what it covers. Click it to preview the full `SKILL.md`.
Use the gear icon to switch between installing into **this project**
(`.claude/skills` — committable, shared with your team) and **your home
directory** (`~/.claude/skills` — available in every project).
